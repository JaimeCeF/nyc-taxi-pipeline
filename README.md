# NYC Taxi Pipeline

A data engineering pipeline for ingesting, transforming, and orchestrating NYC taxi trip data using PySpark, Delta Lake, and AWS.

## Project Structure

```
nyc-taxi-pipeline/
├── ingestion/          # Source connectors / raw data pull jobs
├── transformation/     # Bronze / silver / gold transformation logic
│   ├── bronze/
│   ├── silver/
│   └── gold/
├── orchestration/       # Pipeline scheduling / DAG definitions
├── tests/               # Unit and integration tests
├── requirements.txt
└── pyproject.toml
```
